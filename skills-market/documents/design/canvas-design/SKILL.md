# Static Visual Design

Use the user's intended audience, required text, dimensions and visual direction.
Choose a composition that communicates that content; do not replace a factual
poster with an abstract art manifesto or treat supplied constraints as optional.
A short concept note is useful only when requested or needed for design choices.

Set canvas/page dimensions and export resolution intentionally. Preserve supplied
logos, text and factual claims. Choose typography and hierarchy for the viewing
size; minimal text, thin fonts, geometry and a non-cartoon style are optional choices,
not universal rules. Use bundled `canvas-fonts/` only where a face fits the brief,
covers the needed glyphs and has suitable licensing; preserve its license file.

Keep coordinates, margins, intentional overlaps and cropping controlled. For PDF,
preserve vector text/shapes where useful and embed suitable fonts. For PNG, verify
pixel size and transparency/background intent. Prefer an existing editable/vector
source when the user needs later changes rather than rasterizing unnecessarily.

Render and inspect the delivered artifact at useful viewing size. Check required
content, clipping, legibility, spacing, glyphs and export dimensions; correct actual
problems and recheck affected areas. Do not invent a prior user demand for perfection
or require a second polish cycle when the result already meets the brief.

Deliver only useful requested formats and state any material limitations. Stop
when the composition and output requirements are satisfied; extra pages and a
separate philosophy document are optional follow-ups.
