# Document Coauthoring

Start from the user's existing context, draft, template and intended audience.
Identify the decision or action the document should support. Ask only about gaps
that materially change the result; do not impose fixed rounds of questions or
reconfirm choices already supplied.

Draft a useful structure and content as soon as enough context exists. Follow the
requested destination and format. Use available connected sources within scope
before asking the user to repeat accessible information; do not request routine
approval for a read-only search already covered by the task.

Separate facts, proposals, assumptions and open questions. Preserve source meaning
and confidentiality. A template can guide a substantial draft, but placeholder
scaffolds and 5–20 alternatives per section are not mandatory deliverables.

Edit the actual current document with focused changes. The user may edit directly;
re-read their revisions and preserve them rather than discouraging direct authorship.
Resolve conflicting versions from content/evidence, not merely modification time.

Check whether a reader can recover the purpose, key decision, supporting evidence,
ownership and next action appropriate to this document. A fresh-reader pass can
help a consequential or ambiguous document when available and authorized; it is
not a prerequisite for every section or small correction. Do not claim independent
review when none ran.

Deliver a coherent draft/revision with unresolved facts visible. Stop when it meets
the requested purpose and relevant feedback is addressed; repeated transition
approvals, fixed review loops and user satisfaction questionnaires are optional.
